## Summary: What's Done
- **Full live transcription pipeline**: Mic/WASAPI → VAD → Whisper (3s batches) → WebSocket → React
- **Real-time WebSocket broadcast** with multi-client + auto-reconnect
- **Groq LLM analysis**: Summary, decisions, action items, risks, questions, follow-ups
- **SQLite database** with SQLAlchemy ORM (Meeting, TranscriptSegment, Note)
- **Meeting history** with list, detail, search, edit, delete
- **Audio upload** with transcription + analysis
- **WASAPI loopback** for system audio capture
- **Audio source selector**: Mic / System / Both toggle
- **Minimizable recording modal**: Compact bar while recording continues
- **Full-text search** across meeting titles and transcript segments
- **Multi-language support**: 13 transcription + 12 summary languages
- **Blue-cyan-teal brand theme** with dark/light mode
- **Markdown export** for each meeting

## Summary: What's Left (biggest gaps)
1. **No tests** anywhere (backend or frontend).
2. **No PDF/JSON/TXT export** — only Markdown files on disk.
3. **No pause control** in recording.
4. **No browser-based audio capture** — audio is captured on the backend machine.
5. **Entire Phase 2 (desktop app)** is unstarted.
6. **Hardening**: no Docker, no CI/CD, no long-recording validation.

## Recommended next step
Close the testing gap: add backend unit tests and frontend component tests.
Then tackle export formats (PDF, DOCX) and speaker diarization.

## v001 Changelog

### Added — Database foundation ✅
- `backend/database.py` — SQLite engine (`meetings.db`), `SessionLocal`, `init_db()`.
- `backend/models.py` — ORM models:
  - `Meeting` (id, title, status, started_at, ended_at, duration_seconds, analysis JSON)
  - `TranscriptSegment` (meeting_id FK, sequence, text, speaker, start_sec, end_sec)
  - `Note` (meeting_id FK, content, timestamps)
- `backend/api/routes/meetings.py`:
  - Start inserts `Meeting` row; segments persisted live (own DB session per write)
  - Stop updates `Meeting` row (status=completed, analysis JSON)
  - Endpoints: `GET /meetings/list`, `GET /meetings/{id}`, `DELETE /meetings/{id}`
  - `PATCH /meetings/{id}` for editing title/notes
  - `GET /meetings/search?q=...` for full-text search
  - `GET /meetings/devices` for audio device enumeration
- `requirements.txt`: `SQLAlchemy==2.0.30`
- `.gitignore`: `.env`, `*.db`, caches, logs, frontend build

### Added — Groq LLM Summarization ✅
- `backend/llm/groq_engine.py` — Groq API client with lazy init + health check
- `backend/llm/analyzer.py` — `MeetingAnalyzer` extracts summary, decisions, action items, risks, questions, follow-ups
- Analysis runs automatically on meeting stop and upload
- Language support for 12 summary languages

### Added — Audio Upload ✅
- `POST /upload` endpoint accepts audio files (MP3, WAV, M4A, OGG, FLAC, WebM, MP4, AAC, WMA)
- Transcribes using faster-whisper (full file)

### Added — WASAPI Loopback ✅
